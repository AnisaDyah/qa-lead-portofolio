# Editorial QA Lead Portfolio — Preview

This preview combines the visual identity of the Editorial / Executive concept with the richer information structure of the original portfolio.

## Run locally on macOS

From the project root:

```bash
php -S localhost:8000
```

Open: http://localhost:8000/editorial-preview.php

## What is included

- Editorial homepage with profile, career history, selected case studies, QA leadership approach, technical toolkit, QA artifacts, and contact sections.
- Experience content is stored in `data/experience.json`.
- Project case studies are stored in `data/projects.json`.
- Existing skills, profile, dashboard data, PHP helper functions, original `index.php`, page modules, and original stylesheet remain available.
- The original application entry point and styles have not been overwritten.

## Before public release

- Replace the profile placeholders in `data/profile.json` with approved name and summary text.
- Add real contact URLs and email only after confirming the public details.
- Review employer names, project descriptions, system names, screenshots, and artifacts for confidentiality.
- Add only verified and approved metrics to `data/dashboard.json`.
- Confirm every skill and tool reflects the level of practical experience you want to communicate.
