# QA Lead Portfolio

A modular PHP portfolio website showcasing QA leadership, project management, testing practices, and software development experience.

## Requirements
- PHP 8.0 or newer
- A local PHP development server or PHP-compatible hosting
- Modern browser

## Run locally
From the project root, run:

```bash
php -S localhost:8000
```

Then open http://localhost:8000.

## Project structure
- `config/` application configuration
- `data/` JSON content
- `includes/` shared PHP layout and helper functions
- `pages/` page modules
- `assets/` CSS, JavaScript, and images
- `docs/` project and QA documentation

## Content customization
Update the JSON files in `data/` and replace placeholder copy in `pages/`.
Do not publish employer-confidential details, customer data, credentials, production endpoints, or unapproved screenshots.

## Current scope
V1 uses PHP-rendered pages and local JSON files. No database, login, or admin panel is included.

## Deployment
Deploy to a hosting provider that supports PHP 8+. GitHub Pages does not execute PHP.
